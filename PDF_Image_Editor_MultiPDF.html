PDF Image Editor — Haute Qualité
Chargez un PDF pour commencer.
⚠️ Avant de continuer
Vérifiez toujours la provenance de vos fichiers.

N'importez que des PDF et des images dont vous connaissez l'origine (envoyés par une personne de confiance, téléchargés depuis un site officiel, etc.). Un fichier provenant d'une source inconnue ou douteuse peut contenir du contenu malveillant.
Cet outil traite vos fichiers entièrement dans votre navigateur — rien n'est envoyé à un serveur — mais cela ne protège pas contre un fichier lui-même piégé. La prudence reste de mise avant toute ouverture.
❓ Comment utiliser l'outil ?
1
Importer le PDF
Cliquez sur Choisir un fichier et sélectionnez un ou plusieurs PDF.

Chaque PDF ouvert devient un onglet de document distinct (Onglet 1, Onglet 2, etc.) et ses pages apparaissent juste en dessous.

Vous pouvez rouvrir le sélecteur de fichiers à tout moment pour ajouter d'autres PDF sans fermer les précédents.
2
Copier une page vers un autre PDF
Sélectionnez d'abord l'onglet du PDF contenant la page à copier.

Cliquez sur ☑ Sélectionner puis sur une ou plusieurs pages si vous souhaitez faire une sélection.

Choisissez ensuite le PDF cible dans Copier vers… et cliquez sur 📄➡ Copier vers l'onglet.

La ou les pages sont copiées dans le document cible et ajoutées à la fin. Le document source reste inchangé.
💡 Exemple : depuis l'Onglet 3, sélectionnez la page 4, choisissez l'Onglet 2 et copiez-la : la page 4 est ajoutée en dernière position dans l'Onglet 2.
3
Ajouter une image
Sélectionnez une image avec Choisir un fichier.

L'image apparaît sur la page active.

👉 Faites glisser l'image avec la souris pour la déplacer.
👉 Utilisez le carré bleu en bas à droite pour la redimensionner.
4
Fixer l'image
Lorsque l'image est correctement positionnée, cliquez sur :

✓ Fixer l'image

L'image est alors intégrée définitivement à la page.
5
Supprimer une image
Cliquez sur :

🗑 Supprimer l'image

Si une image est encore en cours de déplacement, elle sera supprimée.

Si aucune image n'est en cours de modification, la dernière image fixée sur la page active sera supprimée.
6
Réorganiser les pages
Utilisez les boutons :

⬅ Déplacer et Déplacer ➡

pour échanger la page active avec sa voisine immédiate.

Les images déjà fixées sur chaque page se déplacent avec elle. Les onglets gardent toujours leur numéro de position (Page 1, Page 2, ...), seul le contenu bouge.
7
Supprimer une page entière
Cliquez sur :

🗑📄 Supprimer la page

La page active (avec toutes ses images fixées) est retirée définitivement du document. Une confirmation est demandée avant la suppression.

Les onglets restants sont automatiquement renumérotés (Page 1, Page 2, ...).

⚠️ Il est impossible de supprimer une page s'il ne reste qu'une seule page dans le document : le document ne peut pas rester vide.
8
Imprimer
Une fois toutes les images correctement placées et fixées, cliquez sur :

🖨 Imprimer toutes les pages

Toutes les pages seront envoyées à l'impression.
💡 Astuce : Pour ajouter une image sur une autre page, sélectionnez d'abord l'onglet de cette page, puis importez votre image.
⚠️ Important : Une image doit être fixée avant l'impression.

Si une image n'est pas fixée au moment de l'impression, l'outil vous demandera si vous souhaitez la fixer.
